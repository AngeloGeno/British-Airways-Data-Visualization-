# ✈️ British Airways Customer Review Dashboard

An interactive Tableau dashboard that analyzes customer reviews of British Airways to uncover trends in passenger satisfaction across different service categories, aircraft types, traveler demographics, and countries.

The project demonstrates business intelligence techniques including interactive filtering, KPI analysis, geographic visualization, and customer experience analytics.

# Project Objectives

This dashboard aims to:

- Analyze overall customer satisfaction
- Compare service ratings across categories
- Identify regional differences in reviews
- Understand traveler behavior
- Evaluate aircraft performance
- Provide interactive insights for decision-makers

---

# Business Questions

The dashboard answers questions such as:

- Which countries provide the highest customer ratings?
- Which aircraft receive the best reviews?
- How do cabin staff ratings compare with entertainment ratings?
- Which traveler type is the most satisfied?
- Which seat class has the highest average rating?
- How has customer satisfaction changed over time?

# Key Insights

- Customer satisfaction varies significantly across countries.
- Cabin staff service consistently receives higher ratings than entertainment.
- Aircraft models show noticeable differences in customer experience.
- Value for Money is one of the strongest indicators of overall customer satisfaction.
- Interactive filtering enables detailed exploration across customer segments.
